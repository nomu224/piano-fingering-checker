# Android Chrome 動作確認手順書(P6)

このアプリを Android スマホ/タブレットの Chrome で動かして確認するための手順です。
仕様書 11 章 P6 の完了条件「Android Chrome 単体で全機能が動く」を確認します。

## 前提

- Android 端末(スマホまたはタブレット)+ Chrome 最新版
  - ※ iPhone/iPad は Web MIDI API 非対応のため対象外(仕様書 2.2)
- **HTTPS の URL**(カメラと MIDI は HTTPS でないと動きません。仕様書 3 章・10 章)
  - 公開方法は 2 通り。どちらかで HTTPS URL を用意する(下記「配信方法」)

## 配信方法(どちらか)

### A. GitHub Pages で公開する(推奨・どこからでもアクセスできる)

1. このリポジトリを GitHub に push する
2. GitHub リポジトリの **Settings → Pages** を開く
3. 「Build and deployment」の **Source** を **「GitHub Actions」** に変更する
4. main(または master)に push すると `.github/workflows/deploy.yml` が自動でビルド&デプロイする
5. Actions タブでデプロイ完了を確認し、表示された URL(`https://<ユーザー名>.github.io/<リポジトリ名>/`)を Android で開く

- **公開範囲について**: 公開されるのは「アプリのページ」だけです。カメラ映像・練習データは端末外に送信されません。
  ソースコードを見せたくない場合はリポジトリを Private にしても Pages 配信は可能です。

### B. 同じ Wi-Fi でローカル配信する(非公開・PC が必要)

1. PC とスマホを**同じ Wi-Fi** につなぐ
2. PC で HTTPS のローカルサーバーを立てる(カメラは localhost 以外では HTTPS 必須のため、
   自己署名証明書か、`@vitejs/plugin-basic-ssl` の導入が必要)
3. スマホで `https://<PC の LAN IP>:<ポート>/` を開く(証明書の警告は許可する)

## 確認チェックリスト

Android Chrome で URL を開いて、以下を順に確認する。

- [ ] **PWA インストール**: メニューから「ホーム画面に追加」でアイコンが追加され、
      アイコンから起動すると全画面(アドレスバーなし)で開く
- [ ] **カメラ権限**: 「P2: カメラ確認」または「P3」タブでカメラ権限を許可 → プレビューが表示される
- [ ] **手の認識**: 手をかざすと 21 点のランドマークが描画される。
      認識状態に **10fps 以上**が出ている(仕様書 10 章。低スペック端末では解像度が影響)
- [ ] **プライバシー明記**: 「カメラ映像は端末の外に送信されません」の文が表示されている(仕様書 10 章)
- [ ] **キャリブレーション**: 「P3」タブで低音・高音の基準鍵盤を登録 → 白線が鍵盤位置に出る
- [ ] **運指判定**: 「P4: 練習」タブで、正しい指=無音、違う指=低いブザー音(ビープ A)、
      違う鍵盤=別の音(ビープ B)。Note On からフィードバックまで遅延が気にならない(仕様書 10 章: 200ms 以内)
- [ ] **結果画面**: 曲を弾き終えると結果サマリーが自動表示。JSON ダウンロードができる
- [ ] **設定**: 音量・判定の厳しさ・判定対象の手を変更できる
- [ ] **縦持ちレイアウト**: 縦持ちで横スクロールが出ず、ボタン・鍵盤がタップしやすい

## トラブルシュート

| 症状 | 確認すること |
|------|------|
| カメラのプレビューが出ない | URL が **https** か / ブラウザのカメラ権限を許可したか / 他アプリがカメラ使用中でないか |
| 手の認識が重い・カクつく | 端末スペックの問題。明るい場所で試す。将来的に解像度を下げる設定を追加予定(仕様書 10 章) |
| ページが真っ白 / アイコンが出ない | GitHub Pages の URL 末尾のスラッシュ(`/<リポジトリ名>/`)を確認 |
| 音が鳴らない | 設定でフィードバック音が ON か / 端末がマナーモードでないか / 一度画面をタップしたか(自動再生制限) |

## 実 MIDI キーボードでの確認(機材入手後)

現状はバーチャル鍵盤(画面タップ)で全機能を確認する。実 MIDI キーボード
(KORG microKEY2 Air 等)を使う場合:

1. Android の設定で Bluetooth MIDI をペアリング(または USB OTG で接続)
2. アプリのデバイス選択に MIDI 入力として現れる(将来 midiInput.ts 実装後)
3. ※ 現時点ではバーチャル鍵盤で代替。実キーボード接続は今後の対応
