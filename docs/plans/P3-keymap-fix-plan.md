# P3 修正計画: 鍵盤位置の補間を「実鍵盤ジオメトリ」に変更(仕様変更・開発者承認済み)

## 背景

P3 の実機テスト(2026-07-07)で開発者から「白線の間隔がまだら。実際の鍵盤は白鍵が等幅なので、
実際の鍵盤と同じにしたい」との指摘・要望があった。

現仕様(F-03 手順 4)は「半音単位で等間隔と近似」だが、実鍵盤は白鍵が等幅で、
ミ・ファ / シ・ドの間には黒鍵がない。このため半音等間隔モデルは実鍵盤に対して
系統誤差を持つ(ドとドで基準を取った場合、シ付近で最大約 0.7 半音 → 警告閾値 0.5 を超える)。

**開発者(プロジェクトオーナー)が「実際の鍵盤と同じにする」方針を承認済み。**

## 変更内容

### 1. 仕様書の改訂(piano-fingering-app-spec.md)

- F-03 手順 4: 「半音単位で等間隔と近似」→「白鍵は等幅、黒鍵は隣り合う白鍵の境目にあるという
  実鍵盤の配置に基づいて補間(鍵盤サイズには非依存)」
- F-03 手順 5: 「0.5 半音間隔(=隣の鍵盤と取り違えるレベル)」→「(=おおよそ隣の鍵盤と取り違えるレベル)」
  (新単位では隣接鍵盤までの距離が黒鍵の有無で 0.86〜1.71 平均半音と一様でないため。レビュー指摘 2)
- 7.2 の信頼度単位の定義: 「隣接鍵盤の x 間隔を 1.0 とする比率」→
  「オクターブ幅の 1/12(平均半音間隔)を 1.0 とする比率」(閾値 0.6 / 0.25 / 0.5 の値は変えない。
  レビューの定量検証により、基準を同ピッチクラス(ド–ド等)で取れば単位は厳密に不変、
  そうでなくても最大 ±5% の揺れで実質不変と確認済み)
- 12 章: 「キャリブレーションが線形補間のため鍵盤サイズには非依存」→
  「実鍵盤ジオメトリ上の線形補間のため鍵盤サイズには非依存」(主張自体は引き続き真。文言を揃える)
- 文末に「変更履歴」節を追加し、変更日・内容・理由を記録(卒論用のトレーサビリティ)

### 2. 実装(src/core/fingerEstimator.ts)

- `keyPosition(midi)` を追加: ピッチクラス → 白鍵単位の位置
  (白鍵 C,D,E,F,G,A,B = 0,1,2,3,4,5,6。黒鍵は境目 = +0.5。1 オクターブ = 7.0)
- `noteToX`: keyPosition 空間での線形補間に変更
- `semitoneWidth`: 「平均半音間隔」= オクターブ幅の 1/12 = 傾き × 7/12 に変更
  (信頼度・ズレの単位はこれまでと同じスケールを保つ)
- キャリブレーションの操作(基準 2 鍵)・データ構造(KeyboardCalibration)・閾値は一切変更なし

### 3. テスト更新

- `tests/core/fingerEstimator.test.ts`: 白鍵が等間隔になることを直接検証(ド→レ、レ→ミ、ミ→ファの
  x 間隔が全て等しい)/ 黒鍵が白鍵の中間に来ること / 補間結果が変わる期待値(レ4・外挿・逆向き)を更新。
  midi 66(ファ♯)はオクターブの厳密な中点のため結果が偶然変わらない — 混乱防止のコメントを付ける
- `tests/vision/calibration.test.ts`: deviationSemitones のレ4(62)の期待値が変わるため更新(レビュー指摘 1)
- テスト用基準がド4–ド5(同ピッチクラス)のため単位 0.05 は不変

### 4. コードコメント・UI 文言の追従(レビュー指摘 4)

- `src/core/constants.ts`: 単位注記を「平均半音間隔(オクターブ幅の 1/12)比」に、
  「隣の鍵盤と取り違えるレベル」→「おおよそ〜」
- `src/core/types.ts`: KeyboardCalibration と FingerEstimateResult の単位注記
- `src/vision/calibration.ts`: deviationSemitones の docstring
- `src/components/CalibrationDebug.tsx`: コメントとユーザー向け警告文言
- `docs/plans/P3-plan.md` は過去の計画のアーカイブなので変更しない

### 5. LESSONS.md への記録

「幾何近似は実物で早期に検証する」教訓を追記。
